# Requirements — Baltiyskiy Bereg

## Functional Requirements

### Core Features

- [ ] **FR-001**: LLM-чатбот подключается к MSSQL-базе сервис-деска (read-only)
- [ ] **FR-002**: Анализирует историю тикетов (Task, TaskFieldValues, TaskExpenses)
- [ ] **FR-003**: Анализирует KB-статьи (KBDocument)
- [ ] **FR-004**: Отвечает на вопросы сотрудников на естественном языке
- [ ] **FR-005**: Помогает создавать и описывать заявки
- [ ] **FR-006**: Предлагает релевантные KB-статьи
- [ ] **FR-007**: Классифицирует заявки (Service / TaskType / Priority)
- [ ] **FR-008**: Использует YandexGPT для генерации ответов

### Integration

- [ ] **FR-010**: Telegram-интеграция
- [ ] **FR-011**: Max (ICQ) интеграция
- [ ] **FR-012**: Битрикс24 интеграция

### User Interface

- [ ] **FR-020**: Веб-интерфейс для тестирования
- [ ] **FR-021**: Админ-панель для управления настройками (желательно)
- [ ] **FR-022**: Дашборд (желательно)

## Non-Functional Requirements

### Performance

| Метрика | Значение | Примечание |
|---------|---------|-----------|
| **NFR-001**: Время ответа | ≤ 30 секунд | Критично для UX |
| **NFR-002**: Нагрузка | 30–50 запросов/сутки | 1-я линия техподдержки |
| **NFR-003**: RPS | ~1 RPS peak | Не критично |

### Quality

| Метрика | Значение | Примечание |
|---------|---------|-----------|
| **NFR-010**: Автоматизация | ≥ 50% | Запросов решается без живого консультанта |
| **NFR-011**: Точность | "Лучше не ответить, чем ошибиться" | Не давать неверные решения |

### Deployment

| Параметр | Требование |
|----------|-----------|
| **NFR-020**: Пилот | SaaS |
| **NFR-021**: Продуктив | On-premise на сервере компании |
| **NFR-022**: Portability | Docker-контейнер |

### Security & Compliance

| Требование | Статус |
|-----------|--------|
| **NFR-030**: Персональные данные | ПДн удалены из БД |
| **NFR-031**: 152-ФЗ | Учесть для архитектуры |

## Data Model

### Primary Tables

| Таблица | Строк | Описание |
|---------|-------|---------|
| `Task` | ~104 000 | Тикеты: Name, Description, Comment (HTML Q&A) |
| `KBDocument` | ~1 060 | Статьи базы знаний |
| `TaskFieldValues` | — | Custom-поля тикетов |
| `TaskExpenses` | — | Трудозатраты: Comments, Minutes, Date |

### Lookup Tables

| Таблица | Описание |
|---------|---------|
| `Service` | Категории услуг |
| `TaskType` | Типы заявок |
| `Status` | Статусы тикетов |
| `Priority` | Приоритеты |
| `KBDocumentTag`, `KBTag` | Теги KB-статей |
| `KBFolder` | Иерархия папок KB |

### Key Fields

#### Task
- `Name` — краткое название проблемы
- `Description` — детальное описание
- `Comment` — HTML Q&A переписка (главный источник для RAG)
- `StatusId`, `ServiceId`, `TypeId` — категоризация

#### KBDocument
- `Name` — название статьи
- `Description` — HTML-содержимое
- `IsPublished` — опубликована?
- `Rating` — рейтинг
